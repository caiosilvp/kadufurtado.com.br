# Kadu Furtado Studio

Crie um site premium, moderno, elegante e altamente profissional para o cabeleireiro e Hair Stylist Kadu Furtado, de Goiânia - GO.

O objetivo principal do site é transformar visitantes vindos do Instagram em clientes e agendamentos.

O site NÃO deve parecer um template genérico de salão de beleza.

Quero uma identidade sofisticada, minimalista e editorial, transmitindo:
- exclusividade
- autoridade
- beleza
- transformação
- atendimento premium
- profissionalismo

ESTILO VISUAL

Criar uma estética inspirada em marcas premium de beleza e moda.

Paleta:
- preto profundo
- off-white
- branco
- tons neutros
- detalhes dourados/champagne muito discretos

Não exagerar no dourado.

Usar bastante espaço negativo, fotografias grandes, tipografia elegante e animações suaves.

O design deve transmitir a sensação de um Hair Stylist de alto padrão em Goiânia.

Evitar:
- visual genérico de barbearia
- excesso de ícones
- excesso de textos
- gradientes chamativos
- elementos neon
- aparência de template pronto
- imagens genéricas demais de banco de imagens

TIPOGRAFIA

Combinar:
- uma fonte serifada sofisticada nos grandes títulos
- uma sans-serif moderna e extremamente legível nos textos

O nome "Kadu Furtado" deve ter grande presença visual.
